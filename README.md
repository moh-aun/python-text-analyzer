# Python Text Analyzer

A simple Python project that analyzes text and generates useful statistics.

## Features
- Character counting
- Word counting
- Sentence counting
- Unique word detection
- Most common word identification

## Technologies
- Python 3
- Built-in Python libraries

## How to Run

1. Install Python 3.
2. Clone this repository.
3. Open the project folder.
4. Run:

```bash
python text_analyzer.py
```

## Learning Objectives
- Python functions
- String manipulation
- Dictionaries and sets
- Loops and conditional statements
- Basic data analysis
